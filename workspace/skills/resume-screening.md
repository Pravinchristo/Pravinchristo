# Resume screening

1. Identify the target role (ask only if there is no way to infer it; check outputs/ and memory for open roles).
2. Score each must-have from 0 to 2 (0 missing, 1 partial, 2 clear evidence), quoting the resume line that supports it.
3. Flag risks: short stints, unexplained gaps, keyword stuffing without project evidence.
4. Verdict: **Advance / Maybe / Reject**, plus 3-5 screening questions that probe the weakest areas.
5. Save the full scorecard to outputs/screening-<candidate>-<date>.md; reply with the verdict and the top 3 reasons.
